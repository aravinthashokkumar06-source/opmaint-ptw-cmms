# Frontend Layer Architecture

* `src/frontend/components/`: Reusable presentation components (Navbar, StatusBadge, CountdownTimer, SignaturePad, QrCodeModal, ConflictBanner).
* `src/frontend/views/`: Screen-level layout views (Permits Dashboard, Detail View, Approval Screen, Closure Screen).
* `src/frontend/forms/`: Adaptive multi-step Permit creation wizard with real-time hazard checklists.
